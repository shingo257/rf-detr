# カービィ連続メッシュアニメーション

`カービィ.png`は頭と胴体が一体の丸いシルエットで、腕と足も本体輪郭へ連続している。
このためパーツ切断ではなく、全身透明PNGを1回だけワープする連続メッシュ方式を使用する。

## リグ

カービィ用リグは画像を分割せず、次の6個のピボットだけを定義する。

- `Body`: 全体の傾き、つぶれ、S字変形
- `Head`: 顔と上半身の傾き
- `Left Arm`, `Right Arm`: 左右の腕周辺
- `Left Leg`, `Right Leg`: 左右の足周辺と接地

各ハンドルはガウス重みで周辺画素へ影響し、離れた画素ほど変形量を小さくする。
顔、輪郭、腕、足を切断しないため、回転時にも切断面は露出しない。

## リグ生成

元画像の周囲へ縦横25%の透明余白を追加し、`464×416`の偶数キャンバスへ配置する。
カービィ本体の大きさは変えず、大きなルート移動でも顔や手足が画面端で切れないようにする。
ピボット、顔保護領域、口の位置は余白追加後の座標へ自動変換される。

```powershell
python scripts\kirby_prepare_mesh_rig.py `
  --input カービィ.png `
  --output artifacts\kirby_mesh_rig
```

## 動画生成

ふっかちゃんで生成したRF-DETR全身制御JSONを共通入力として利用できる。

```powershell
python -m rfdetr_demo.animation.puppet_cli `
  --controls artifacts\fukkachan_torso\mzoo_fullbody_controls_full_stride6.json `
  --rig artifacts\kirby_mesh_rig `
  --output artifacts\kirby_animation\kirby_mzoo_expression_full_40fps_v10.mp4
```

## カービィ用プロファイル

- 頭角度ゲイン: `0.65`
- 胴体角度ゲイン: `0.60`
- S字ゲイン: `0.45`
- 腕角度ゲイン: `0.70`
- 脚角度ゲイン: `0.60`
- 腕影響半径: 横`0.28`、縦`0.30`
- 脚影響半径: 横`0.23`、縦`0.25`

人体の角度を直接適用せず、円形輪郭と顔の読みやすさを保つ範囲へ抑えている。

## 顔表情

- 目を含む顔中央は身体・手足のメッシュ変形から保護し、頭部の剛体回転だけを適用する。
- 両目と左右の頬には個別の楕円保護領域を重ね、腕変形が顔へ侵入するのを防ぐ。
- 口は閉じた線を引き伸ばさず、口内、輪郭、舌を持つ専用表情へ差し替える。
- 開口サイズは透明余白を除いた元画像寸法を基準にし、キャンバス拡張で口が過大化しないようにする。
- 開口時の肌は固定色で塗らず、元画像の口周辺から肌色を自動採取した口なし下地を先にメッシュ変形する。
- 最大開口へ近づくほど両目を約2%分上へ移動し、縦横比を維持したまま最大5.5%縮小する。
- `mouth_open`は腕、脚、足上げ、上下動の運動量から生成し、二次動作フィルターで滑らかにする。
- COCO17には口ランドマークがないため、現段階の口はダンサーの発話ではなく動作強度へ同期する。

## 検証結果

- 完成動画: `artifacts/kirby_animation/kirby_mzoo_expression_full_40fps_v10.mp4`
- フレーム数: 1270
- fps: 40.638
- 尺: 31.252秒
- 解像度: 464×416
- 入力キーポイント: RF-DETR 212キーフレーム、stride 6
- 補間: 元動画fpsへ1270フレーム補間
- 二次動作と足接地: 有効
- 大口フレーム: 627

カービィの輪郭は全フレームで1枚の連続面として描画され、分割境界は存在しない。
